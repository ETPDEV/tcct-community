# TCCT Community Edition

**Termux Claude Code Toolkit** - Transform your Android phone into an AI development workstation.

## Features (Free)

- Local LLM support (Qwen2.5-3B, completely free)
- 5 AI agents: Writer, Reasoner, Planner, Debugger, Support
- Hybrid routing for smart model selection
- Persistent memory system
- CLI interface

## Quick Start

```bash
# 1. Clone the repo
git clone https://github.com/ETPDEV/tcct-community.git
cd tcct-community

# 2. Install dependencies
pip install -r requirements.txt

# 3. Setup local model (one-time)
./scripts/tcct setup

# 4. Start using
./scripts/tcct ask "Hello, world!"
./scripts/tcct agent list
./scripts/tcct agent run writer "Write a poem"
```
